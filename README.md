# E-Commerce Behavioral & Sales Performance Dashboard

### ⚠️ Important Notice Regarding Data File
Due to GitHub file size limits, the raw dataset (`RawData.csv`) which is around 300MB is not uploaded with the project files.
**To run this project correctly on your machine, follow these steps:**
1. Download the data file directly from Google Drive [by clicking here](https://drive.google.com/file/d/1-MrmZYw3Cii04jcRqebvvHsUAkzy5SIe/view?usp=drive_link).
2. Move the downloaded file into the `Resources` folder.
3. Make sure the file is saved exactly as: `RawData.csv` (case-sensitive, with no extra characters).
